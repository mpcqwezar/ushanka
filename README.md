# Шляпа

Веб-версия игры «Шляпа» для компании: один телефон передаётся по кругу.

## Как играть

1. Добавьте игроков и слова (есть русский словарь по умолчанию).
2. Выберите время хода и сколько слов взять в партию.
3. Перед каждым ходом — экран «Передай телефон»; слово скрыто, пока не нажато «Готов».
4. Объясняющий описывает слово слушателю. **Угадали** — слово уходит из шляпы, оба получают +1. **Пропуск** — слово в конец очереди.
5. По окончании таймера — ещё одно последнее действие, затем ход следующего игрока.
6. Игра заканчивается, когда шляпа пуста (или вручную).
